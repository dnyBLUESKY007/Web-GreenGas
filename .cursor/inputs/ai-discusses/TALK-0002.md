# 还有一个更符合B2B逻辑的组织方式

实际上很多工业企业最后都会采用：

```
Solutions（解决方案）
Projects（案例）
Products（产品）
About（关于我们）
Contact（联系我们）
```

而不是：

```
Products
Solutions
Projects
```

原因很简单：

客户关心顺序是：

"你能解决我的问题吗？"

↓

"你做过类似项目吗？"

↓

"你具体用什么设备？"

↓

"你们是什么公司？"

这恰好对应：

```
Solutions
→ Projects
→ Products
→ About
```

如果GREENGAS未来重点做定制化项目、政府项目、工业项目，我建议把“解决方案”作为核心入口，把“案例”作为信任背书，把“产品”降级为支撑内容，而不是反过来。这样更符合工业自动化、暖通工程、系统集成类企业的获客逻辑。

# 案例为什么排在产品前面

因为案例证明：

> 你说的不是PPT。

对于工业客户：

产品参数是宣传。

案例才是证据。

例如：

---

产品页面说：

```text

```

客户半信半疑。

---

案例页面说：

```text
某铸造厂
环境温度55℃
连续运行两年
```

客户立刻相信。

---

所以案例的作用是：

```text
方案 = 承诺

案例 = 证据

产品 = 实现手段
```

这是三个层级。

# GREENGAS 官网首页信息架构设计说明

## 一、设计目标

本项目为 GREENGAS（格灵空调）官方网站，企业定位为：

> 面向工业企业、商业建筑、政府及公共设施等客户，提供定制化制冷系统解决方案，涵盖方案设计、设备制造、安装调试、售后服务等完整流程。

本网站并非电商网站，也不是产品目录，而是 **B2B 工程型企业官网**。

首页的目标不是介绍企业全部内容，而是在有限时间内完成三个目标：

1. 让客户快速理解企业业务定位。
2. 建立企业专业能力与可信度。
3. 引导客户继续浏览二级页面或主动联系。

首页承担"建立信任"和"激发兴趣"的职责，而详细参数、企业历史、完整案例等内容交给二级页面。

# 二、整体设计理念

整个首页遵循以下设计原则。

## 1. 信息优先，而非页面优先

首页不是按照"公司简介、产品中心、联系我们"等传统栏目依次排列，而是按照客户获取信息的逻辑组织。

所有页面都应回答一个明确的问题，每一屏只表达一个核心主题。

避免在一屏内混合多个互不相关的信息。

---

## 2. 控制信息密度

不是每个模块都需要占据一个完整屏幕。

根据实际内容多少决定视觉权重。

例如：

Hero 可以占较大视觉面积。

企业简介只有一段文字，则无需独立一屏。

联系方式也无需独立一屏。

保持页面节奏紧凑，减少滚动距离，提高阅读效率。

---

## 3. 首页强调能力，而不是产品

对于定制化工程企业而言：

客户首先购买的是：

* 解决方案能力
* 工程经验
* 项目交付能力
* 售后保障能力

产品只是能力落地的载体。

因此首页的信息组织应该体现：

解决什么问题

能力如何

是否做过类似项目

最后才展示产品体系。

---

## 4. 每一屏只有一个信息中心

例如：

第一页告诉客户：

"我们是谁，我们解决什么问题。"

第二页告诉客户：

"我们在哪些场景具有成熟经验。"

第三页告诉客户：

"为什么相信我们的能力。"

不要在同一屏内加入大量无关信息。

---

## 5. 信息与视觉共同控制阅读节奏

图片负责建立第一印象。

文字负责传递专业信息。

留白负责调节阅读节奏。

不要为了铺满页面而增加内容。

# 四、整体视觉节奏

首页整体应形成由"感性"逐渐过渡到"理性"的信息节奏。

第一屏强调品牌形象与第一印象，以高质量视觉建立信任。

第二屏开始进入业务层面，围绕应用场景说明企业能够解决哪些实际问题。

第三屏进一步证明企业具备完成项目的能力，通过工程流程与真实案例建立专业可信度。

第四屏介绍产品体系与服务能力，帮助客户理解企业具体提供哪些产品与支持。

第五屏完成品牌收束，通过企业信息、资质与联系方式引导客户进入下一步沟通。

整个浏览过程应符合 B2B 客户的认知路径：**先理解企业定位，再理解业务能力，再看到能力证明，最后了解产品体系，并最终完成联系转化。**

# 五、AI IDE 实现原则

在具体实现过程中，应始终遵循以下原则：

* 首页优先展示企业能力，而不是产品数量。
* 每一屏只围绕一个核心主题组织信息，避免信息混杂。
* 信息密度决定模块高度，不为"凑满一屏"而增加内容。
* 每个模块都应有明确的视觉重心（Visual Focus），避免多个元素竞争注意力。
* 图片承担氛围与场景表达，文字承担专业信息传递，两者相辅相成。
* 保持充足留白与统一的设计语言，使浏览节奏张弛有度。
* 每一屏都应提供清晰的下一步入口（如"查看解决方案""浏览案例""了解产品""联系我们"等），让首页不仅是展示页，也是网站导航的起点。

整个首页应传递的核心印象不是**"GREENGAS 有很多空调产品"**，而是：

> **GREENGAS 是一家能够理解客户业务场景、具备完整工程实施能力，并能提供定制化工业与商业制冷解决方案的专业合作伙伴。**

如果 AI IDE 在设计过程中遇到视觉或布局上的取舍，应始终优先保证这一核心定位能够被准确、清晰地传递。
