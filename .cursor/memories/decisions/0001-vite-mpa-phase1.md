# ADR-0001: Phase 1 使用 Vite MPA，不引入 UI 框架

- **状态**：已采纳
- **日期**：2026-06-18

## 背景

GREENGAS 官网本质是「展示内容 → 用户阅读 → 联系企业」，非复杂交互系统。需在短期内交付高质量静态站，同时为内容扩展（CMS、博客）和业务系统（CRM）预留演进路径。

## 决策

Phase 1 采用 **Vite + TypeScript + SCSS 多页静态站点（MPA）**，用原生 DOM 操作渲染组件，**不引入** React、Vue、Next.js 或 Astro。

## 备选方案

- **Astro（Phase 2）**：SEO 与内容管理更强 — 当前内容量尚小，迁移成本不值得现在就引入
- **React / Next.js（Phase 3）**：适合业务系统 — 官网无状态管理、路由复杂度需求，过度工程化
- **散落 HTML 文件**：无构建工具 — 无法保证类型安全、SCSS 模块化与开发体验

## 影响

- **正面**：构建快、依赖少、AI 协作 diff 小、部署简单（纯静态）
- **负面**：组件复用靠 TS 函数而非 JSX，复杂交互需手写 DOM
- **后续**：当需要 CMS / 博客 / 增强 SEO 时迁移至 Astro（Phase 2）
