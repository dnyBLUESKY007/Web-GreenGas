# ADR-0003: 自研轻量 i18n 层

- **状态**：已采纳
- **日期**：2026-06-21

## 背景

甲方要求中英俄三语。Phase 1 仅需 UI 文案切换 + JSON 结构化字段多语言后缀，不需要多语言路由或复杂复数/插值。

## 决策

自研轻量 i18n：`i18n/locales/*.json` 存 UI 文案，`td()` 函数读取 JSON 数据字段的 `_zh` / `_ru` 后缀，缺省回退英文；语言偏好存 `localStorage`。

## 备选方案

- **i18next / vue-i18n 等**：功能全面 — 增加依赖，Phase 1 需求过于简单
- **独立构建 per locale**（`/en/`、`/zh/`）：SEO 更好 — Phase 2 Astro 再评估，当前运行时切换足够
- **仅中文**：不符合甲方 6/21 三语 scope

## 影响

- **正面**：零第三方依赖、与 JSON 数据层自然融合
- **负面**：无 ICU 复数、无 SSR 语言路由；大型翻译管理需手动维护 JSON
- **后续**：Astro 迁移时可保留 `_zh`/`_ru` 字段约定
