## 一、国内工业/特种空调企业（同业参考）

### 1. 智盛宏明（智盛）

**链接：** https://www.zshmkt.com/company/production

**内容概要：** 广东智盛宏明空调设备有限公司，2018 年成立；集研发、设计、制造、营销、运营维护于一体，主营工业领域特种空调设备。产品矩阵：工业空调、储能/预制舱空调、防腐/高温/恒温恒湿/防爆空调、非标定制。应用领域：电力、储能、石化、机械、冶金、军工等。

**设计理念：** WordPress 定制主题，固定顶栏 + 多级下拉导航；子页面 Banner + 二级 Tab 导航；图文左右分栏；页头集成搜索、电话直拨。整体：传统企业官网，信息密度高，强调 B2B 信任背书。

### 2. 锐劲特

**链接：** https://www.risita.com.cn/about

**内容概要：** 广东锐劲特，佛山 + 郑州双生产基地。产品：工业/防腐/防爆/储能/电气室空调等。服务国家电网、大唐、华润、中石化等重点工程。研发 20 人团队，30+ 专利。

**设计理念：** 与智盛类似 WordPress 工业主题；关于页 Tab 切换（企业简介 / 文化 / 社会责任 / 服务 / 生产设备）；左图右文 + 企业视频 + 资质证书轮播。强调「专业、创新、节能、可靠」。

### 3. 日高

**链接：** https://www.tzrigao.com/

**内容概要：** 日高冷机（江苏），专注特殊环境制冷：极限高低温、盐雾/酸性腐蚀、沙漠戈壁等。六大行业应用：机电、电力、通讯、光伏储能、无人机、钢铁。数据背书：2009 创立、3 天生产周期、1000+ 客户。

**设计理念：** 更现代化：全屏 Slogan + 视频入口 + 产品/应用/数据/客户 Logo/新闻多区块。行业应用 Tab/卡片切换。偏「特种环境专家」定位，场景化叙事。

### 4. 格灵

**链接：** https://cn.greennb.com/aboutus.html

**内容概要：** 宁波格灵空调，高新技术企业。品牌理念 **SPEC**：服务当先、专业团队、品质卓越、性价比高。产品：中央空调主机、单元机、末端与部件。服务钢铁、化工、电力、制药、军工。

**设计理念：** 传统 B2B 门户：顶部搜索 + 产品树 + 关于页 Tab。SPEC 四字母价值观视觉化；产品分类层级深，catalog 思路。

## 二、国际 HVAC / 制冷 / 工业温控品牌

### 5. Lennox

**链接：** https://www.lennox.com/

**内容概要：** 美国百年 HVAC 品牌，Residential + Commercial 双线。强调「Perfect Air」— 让空气更凉、暖、干、净、好。

**设计理念：** 高端消费级视觉：全宽轮播 Hero、大图 + 短文案 + CTA。双受众并行（Homeowners / Dealers / Commercial Contractors）。品牌叙事围绕「空气品质」。

### 6. STULZ

**链接：** https://www.stulz.com/en-us/products/detail/cyberaircwanddx/

**内容概要：** CyberAir CW/DX：数据中心 perimeter CRAC/CRAH，20 kW–1080 kW。品牌口号 **「Climate. Customized.»**

**设计理念：** 典型 B2B 产品详情页：Hero + Tab（Overview / Benefits / Features / Technical Data）。技术参数表格化；文档下载；工程师友好，少营销话术。

### 7. Copeland / Vilter

**链接：** https://www.copeland.com/en-us/products/refrigeration/industrial-refrigeration

**内容概要：** 150 年工业制冷创新，单螺杆压缩机（氨、CO₂）。行业：食品饮品、冷库、工业加工、冰场。

**设计理念：** Jump to section 锚点导航、行业卡片分栏、产品 Tab。可持续叙事 + Case Study。

### 8. Aggreko

**链接：** https://www.aggreko.com/en-ca/products/hvac/cooling/air-conditioners

**内容概要：** 临时/租赁工业空调，1–70 吨。场景：应急备份、季节性调温、活动会展、维护窗口。

**设计理念：** 问题—方案—能力—行业—FAQ 结构。强调 Expert advice / Minimal disruption。租赁模式侧重「快速响应」。

### 9. Daikin

**链接：** https://www.daikin.com/products/ac

**内容概要：** 全球空调品牌，「Perfecting the Air」。产品全品类：分体/VRV/冷水机/屋顶机/船用 HVAC 等。

**设计理念：** 全球化 mega menu、区域切换。产品页为分类索引 + Advantage 四象限 + Case Study。简洁、国际化。

### 10. ISP Canada

**链接：** https://ispcanada.com/industrial-air-conditioning/

**内容概要：** 面向钢铁/采矿的重型工业空调，极端工况：冷凝温度至 190°F/88°C。

**设计理念：** 极简 niche 站点；用极限参数数字建立专业权威。典型北美小型工业品制造商网站。

## 五、跨站点设计理念对照（web-greengas 可借鉴）

| 维度 | 国内同业 | 国际 HVAC | 重工品牌 |
|------|----------|-----------|----------|
| **首页焦点** | 产品分类 + 行业应用 + 案例 | 品牌主张 + 解决方案 + 双受众分流 | 产品 Carousel + 品牌故事 + CTA |
| **导航** | 深层产品下拉 + 关于子 Tab | Mega menu + 区域/语言切换 | 车型/产品线 + Dealer Locator |
| **信任建立** | 资质、重点工程客户、产量数据 | Case Study、认证、TCO/节能数据 | 排名/奖项、社会责任、证言视频 |
| **视觉风格** | 传统企业站、信息密度高 | 现代留白、摄影/视频、模块化 | 大片 Hero、高端工业美学 |
| **转化路径** | 电话 / 在线留言 | 表单 + 本地代表 + 文档下载 | Build Yours / Find Dealer |

**共性要点：**

1. **行业场景化** — 按电力/储能/钢铁/数据中心等场景组织内容
2. **极端参数可视化** — 高温、防腐、防爆等用具体数字和案例证明
3. **B2B 信任链** — 资质证书、标杆客户 Logo、产量/年限 KPI、ISO 体系
4. **清晰 CTA** — 电话、经销商、询价表单、文档下载至少其一在首屏可达
5. **分层信息架构** — 集团品牌 vs 产品详情 vs 区域市场页面结构匹配受众
