## 内容提取规则

- 文章页：提取 `.articledetail-cont` 内正文，忽略导航、侧栏、页脚与分享组件。
- 公司页：提取 `.sitewidget-text` 中有实质内容的文本块，并下载正文相关图片。
- 图片：优先使用 `data-original` 真实地址，跳过 lazyload 占位图。
- 重复 URL（同时出现在工程案例与新闻列表）仅爬取一次，在 front matter 中用 `also_in` 标注。
