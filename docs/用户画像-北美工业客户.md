# 北美工业客户用户画像

> 本文档基于 GREENGAS 目标市场（工业制冷 / HVAC 定制方案）整理，供官网内容、视觉与信息架构决策参考。  
> 配套 AI 设计规则见 [`.cursor/rules/project-related/website-design.mdc`](../.cursor/rules/project-related/website-design.mdc)。

---

## 1. 核心差异（为何不能「翻译式出海」）

| 维度 | 东亚客户 | 北美工业客户 |
|------|----------|--------------|
| 信任来源 | **规模感** — 大不大、稳不稳 | **专业感** — 能不能解决问题 |
| 首屏关注 | 企业大楼、董事长、员工数 | 业务是什么、与我何关 |
| 视觉偏好 | 震撼大图、深色科技风、高密度 | 白底留白、克制、可扫描 |
| 文案风格 | 行业领先、国家级、赋能 | 具体项目、 measurable 结果 |
| 联系偏好 | 表单提交、等待回复 | 电话 / Email 直接触达 |

**结论：** 把国内官网直译英文，欧美客户易感知为「不可信 / 像诈骗站」。GREENGAS 应采用 **70% 北美工业官网逻辑**，国内资质与规模模块后置展示。

## 2. 主要受众

### 角色

- 设施经理（Facility Manager）
- 工厂 / 运营经理（Plant / Operations Manager）
- 工程经理（Engineering Manager）
- 采购团队（Procurement）
- 政府项目评审人员
- 咨询工程师（Consulting Engineer）

### 共同特征

- **B2B 专业人士**，非普通消费者
- 通常带着**具体项目或痛点**访问网站
- 时间有限，**10 秒内**找不到答案会离开
- 理性决策，重视证据而非口号

### 典型访问场景

- 工厂降温 / 工业 HVAC 改造
- 数据中心热管理
- 实验室温湿度控制
- 船用、高温、防爆等特殊环境空调
- 大型商业 /  institutional 冷却系统

## 3. 用户心智模型

### 不会问

- 这家公司有多大？
- 董事长是谁？
- 办公楼漂不漂亮？

### 一定会问（按顺序）

1. **What do you do?** — 你们到底做什么？
2. **Can you solve my problem?** — 能解决我的问题吗？
3. **Why should I trust you?** — 凭什么信你？
4. **How do I contact you?** — 怎么联系？

### 信任如何建立

✅ 相关案例、工程过程、技术能力、认证、真实项目照片  
❌ 空洞自称「行业领先」「创新驱动」

> *If you're really good, show me.*

## 4. 浏览行为与页面期望

### 北美工业官网典型路径

```
首页 → 解决方案 → 案例 → 联系我们（结束）
```

极其直接，无需翻阅「集团介绍 → 领导关怀 → 企业文化」。

### 推荐首页结构（兼顾国内客户）

| 顺序 | 模块 | 主要服务 |
|------|------|----------|
| 1 | Hero — 明确业务 | 北美 |
| 2 | 解决方案 | 北美 |
| 3 | 行业应用 | 北美 |
| 4 | 案例 | 北美 |
| 5 | 资质与项目数据 | 国内 |
| 6 | 公司简介 | 国内 |
| 7 | 联系方式 | 双方 |

### 停留时间与信息密度

- **5 秒**：理解业务类别
- **15 秒**：找到与自己行业/场景相关的内容
- **30 秒**：获得至少一个信任锚点（案例、数据、认证）
- 接受短段落、要点列表；**拒绝**长文堆砌与营销黑话

## 5. 视觉与内容偏好

### 视觉

| 偏好 | 避免 |
|------|------|
| 白 / 浅灰背景、大量留白 | 大面积深色 + 粒子 / 地球 / 光束 |
| 品牌色少量点缀（深绿 `#163B31`） | 霓虹、过度渐变 |
| 横向可扫描布局（卡片、多栏） | 窄栏长文垂直堆叠 |
| 功能性微动效 | 无信息娱乐性动画 |

**参考站点气质：** Carrier、Trane Technologies、Johnson Controls、Daikin Applied、Lennox

### 图片

| 优先级 | 内容 |
|--------|------|
| 高 | 工程现场、已装系统、设备细节、工程师作业、应用场景 |
| 低 | 办公楼、园区航拍、领导视察、员工大合影 |

**文案对比：**

- 弱：*拥有 30,000 平方米生产基地*
- 强：*帮助某数据中心降低 32% 能耗*

### 文案

| 类型 | 示例 |
|------|------|
| ❌ 空洞 | Leading HVAC Solution Provider / Dedicated to Innovation |
| ✅ 具体 | Custom Cooling Systems for Industrial Facilities / Designed and Installed 300+ Cooling Projects |

关键词倾向：Cooling Solutions、Industrial HVAC、Engineering Services、Project Experience、Energy Efficiency、Facility Cooling

## 6. 联系方式期望

- 希望**立即**看到：电话、Email、WhatsApp、地址（及 LinkedIn 如有）
- 表单可作为补充，**不应**是唯一入口
- FAQ 有效（定制能力、工厂参观等常见问题）

## 7. 品牌人格（网站应传递）

| 特质 | 含义 |
|------|------|
| **Reliable** | 项目能按时、按质交付 |
| **Professional** | 工程能力贯穿全站 |
| **Helpful** | 可接近、以解决方案为导向 |
| **Stable** | 不追逐潮流、不激进 |
| **Practical** | 强调真实结果，非 slogans |

## 8. 与甲方需求的映射

| 甲方要求 | 用户画像解读 |
|----------|--------------|
| 白底黑字、克制得体 | 对齐北美工业站审美，建立专业信任 |
| 主页图为主、字少 | 符合 10 秒决策窗口，快速传达「做什么」 |
| 按场景分产品详情 | 直接回答 *Can you solve my problem?* |
| 公司简介独立页 | 规模/历史信息后置，不抢首屏 |
| 多渠道联系方式 + FAQ | 满足北美「直接联系」+ 降低咨询门槛 |

## 9. 设计验收清单

在发布或改版任何页面前，确认：

- [ ] 5 秒内能回答：这家公司做什么？
- [ ] 15 秒内能回答：与我的行业/场景是否相关？
- [ ] 30 秒内能回答：为什么值得联系他们？
- [ ] 首屏无「行业领先 / 赋能 / 引领未来」等空洞词？
- [ ] 图片以工程与设备为主，非大楼航拍？
- [ ] 联系方式在首屏或固定导航可见？
- [ ] 视觉是否更像 Carrier / Lennox，而非国内科技粒子风？

**原则：清晰度 > 视觉复杂度。**
