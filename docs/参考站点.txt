## 一、国内工业/特种空调企业（同业参考）

### 1. 智盛宏明（智盛）
**链接：** https://www.zshmkt.com/company/production

- 集研发、设计、制造、营销、运营维护于一体，主营工业领域特种空调设备。
- 产品矩阵：工业空调（风冷/水冷柜机、屋顶机、直膨机组、模块机、螺杆冷水机）、储能/预制舱空调、防腐空调、高温特种空调、恒温恒湿/机房空调、防爆空调、非标定制。
- 应用领域：电力、储能、石化、机械、冶金、军工、造纸、玻璃、工业冷冻、精密控制、食品药品等。
- 企业文化强调：以客户为中心、诚信、团队合作、持续创新、质量至上、社会责任。

**设计理念：**
- WordPress 定制主题，固定顶栏 + 多级下拉导航（产品分类嵌套子类）。
- 子页面 Banner + 二级 Tab 导航（公司简介/历史/文化/荣誉/优势/质量/董事长致辞）。
- 中英混排标题（如 "About hongming"），图文左右分栏展示企业介绍。
- 价值观以卡片/列表块呈现；页头集成搜索、电话直拨（13602262517）。
- 整体风格：传统企业官网，信息密度高，SEO 与百度统计集成，强调 B2B 信任背书。

## 五、跨站点设计理念对照（web-greengas 可借鉴）

| 维度 | 国内同业（智盛/锐劲/日高/格灵） | 国际 HVAC（Lennox/Daikin/STULZ 等） | 重工品牌（三一/Volvo/SANY US） |
|------|--------------------------------|--------------------------------------|--------------------------------|
| **首页焦点** | 产品分类 + 行业应用 + 案例 | 品牌主张 + 解决方案 + 双受众分流 | 产品 Carousel + 品牌故事 + CTA |
| **导航** | 深层产品下拉 + 关于我们子 Tab | Mega menu + 区域/语言切换 | 车型/产品线 + Dealer Locator |
| **信任建立** | 资质、重点工程客户、产量数据 | Case Study、认证、TCO/节能数据 | 排名/奖项、社会责任、证言视频 |
| **视觉风格** | 传统企业站、信息密度高 | 现代留白、摄影/视频、模块化 | 大片 Hero、高端工业美学 |
| **转化路径** | 电话 / 在线留言 | 表单 + 本地代表 + 文档下载 | Build Yours / Find Dealer |
| **内容策略** | 特种工况 + 行业垂直 | 技术参数 + 可持续叙事 | 情感品牌 + 本地化服务 |

**共性要点：**
1. **行业场景化** — 优秀站点均按电力/储能/钢铁/数据中心等场景组织内容，而非仅列产品型号。
2. **极端参数可视化** — 高温、防腐、防爆等差异化用具体数字和案例证明（日高、ISP、STULZ）。
3. **B2B 信任链** — 资质证书、标杆客户 Logo、产量/年限 KPI、ISO 体系几乎标配。
4. **清晰 CTA** — 电话、经销商、询价表单、文档下载至少其一在首屏可达。
5. **分层信息架构** — 集团品牌（三一） vs 产品详情（STULZ） vs 区域市场（SANY America）页面结构应匹配受众。
