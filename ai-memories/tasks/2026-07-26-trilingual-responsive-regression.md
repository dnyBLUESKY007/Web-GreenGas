## Problem / 目标

## 核心思路

遵守 PRD“不引入新的自动化浏览器测试框架”的决定：扩展现有 Node 契约测试以覆盖三语键一致性、数据引用完整性、base path、响应式断点和关键交互约束；同时运行根路径与子路径生产构建。对必须依赖真实浏览器或远端服务的事项进行独立探测并如实记录，不用静态断言冒充视觉验收。

优先修复可确定的跨模块缺陷：产品与行业 ID 不一致、行业示例案例被错误渲染为可用详情链接、动态 FAQ 锚点未在渲染后定位、全局可访问名称未本地化、轮播未尊重减弱动态偏好、俄文新闻卡固定高度溢出，以及已登记但远端不可用的图片资源。

## Lessons Learned

> 任务收尾时填写，供后续任务参考；重要结论应同步回 `ai-memories/memories/`。

- 数据文件中的稳定 ID 必须做跨集合引用检查；仅断言链接模板存在会放过可点击 404。
- 固定高度配合绝对定位不适合三语卡片，尤其俄文；自然高度 Grid 能以更少规则覆盖中宽与桌面宽度。
- 资源登记只证明溯源，不证明 OSS 对象已上传；发布验收必须独立探测可用性，并在运行时提供诚实的失败状态。
- 动态插入的片段目标需要在渲染后重新定位；URL 中存在 hash 不代表浏览器一定会滚动到延迟创建的元素。
