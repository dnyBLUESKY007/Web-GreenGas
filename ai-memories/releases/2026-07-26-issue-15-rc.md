## 重建步骤

在 `frontend/` 执行：

```bash
npm ci
npm run typecheck
npm run test
npm run build
tar --sort=name --mtime='UTC 1970-01-01' --owner=0 --group=0 --numeric-owner -cf - dist | sha256sum
rm -rf dist
VITE_BASE=/rc/ npm run build
tar --sort=name --mtime='UTC 1970-01-01' --owner=0 --group=0 --numeric-owner -cf - dist | sha256sum
```
